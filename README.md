# CCHS JobLink

CCHS JobLink is a web-based platform built to connect students at CCHS with local job opportunities. It facilitates communication between students and employers while also providing tools for application management, resume submission, and more.

## 🔧 Features

- 🧑 Student & Employer registration
- 💼 Job posting and approval system
- 📝 Resume & cover letter upload
- 📆 Application tracking
- 💬 Real-time messaging system
- 📢 Notification system
- 🔒 Admin dashboard for managing listings
- 🧑‍💼 User profiles with bios, skills, education, and contact info

## 🖼️ Technologies Used

- Python / Flask (backend)
- HTML / Bootstrap (frontend)
- SQLite (database)
- SQLAlchemy (ORM)
- JavaScript (dynamic UI updates)
